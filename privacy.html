AutoClip privacy policy

Last updated: 23 November 2026

AutoClip is a personal tool that runs on its owner's own computer. It is used only by its owner, for the owner's own YouTube channels.

What Google data AutoClip uses

With the owner's permission, AutoClip uses the YouTube Data API to upload videos, set their titles, descriptions and tags, set custom thumbnails, and read basic channel details (channel name and upload status).

How it is stored

Sign-in tokens and posting records are stored only on the owner's computer. Nothing is sent to any server other than Google's.

Sharing

AutoClip does not sell, share or transfer any data to third parties, and does not use it for advertising.

AutoClip's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. AutoClip uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting AutoClip's data folder on the owner's computer removes all stored data.
